## Which Exoplanets Are Most Similar to Earth?

As part of this project for a course on Unsupervised Machine Learning, I apply Gaussian Mixture Models (GMM) and K-means clustering to identify groups of exoplanets with characteristics similar to those of Earth. The goal is to identify exoplanets that may share Earth's physical properties and potentially have conditions suitable for life.


The data was extracted from \href{https://exoplanetarchive.ipac.caltech.edu/}{"NASA Exoplanet Archive"}, um catálogo de dados que contém informações sobre estrelas e exoplanetas. Também foi utilizado um banco de dados sobre os planetas do Sistema Solar disponibilizado pela \href{https://nssdc.gsfc.nasa.gov/planetary/factsheet/}{NASA}.
